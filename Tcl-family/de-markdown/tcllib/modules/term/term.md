# BESCHREIBUNG

Es ist vorgesehen, dass dieses Paket allgemeine Befehle zur Terminalsteuerung auf hoher Ebene bereitstellt, ähnlich wie ncurses oder vergleichbare Pakete. Derzeit ist jedoch noch nichts implementiert. Das heißt, dieses Paket ist leer. Es kann zwar geladen werden, bietet jedoch keine Funktionen.
