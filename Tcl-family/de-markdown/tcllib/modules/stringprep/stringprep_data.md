# Beschreibung

Das Paket **stringprep::data** ist ein Hilfspaket für **stringprep** und stellt diesem die Datentabellen bereit, die es für seine Funktionen braucht. Es ist ein *internes* Paket, auf das nicht eigenständig zugegriffen werden sollte. Deshalb hat es auch keine öffentlich dokumentierte API. Seine Implementierung wird durch ein Skript erzeugt.
