# Beschreibung

Dieses Paket stellt den NTLM-Authentifizierungsmechanismus für das Simple Authentication and Security Layer (SASL) bereit.

Bitte lesen Sie die Dokumentation zum Paket **sasl**, um weitere Einzelheiten zu erfahren.
