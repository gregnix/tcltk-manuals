# Name

SASL::SCRAM – Implementierung des SASL-SCRAM-Mechanismus für Tcl

# Beschreibung

Dieses Paket stellt den SCRAM-Authentifizierungsmechanismus für die Simple Authentication and Security Layer (SASL) bereit.

Bitte lesen Sie die Dokumentation zum Paket **sasl**, um weitere Einzelheiten zu erfahren.

# Literatur

1. Newman, C. et al., „Salted Challenge Response Authentication Mechanism (SCRAM) – SASL- und GSS-API-Mechanismen“, RFC 5802, Juli 2010, (<http://www.ieft.org/rfc/rfc5802.txt>)
