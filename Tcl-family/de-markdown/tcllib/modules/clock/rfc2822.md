# Name

clock\_rfc2822 – Parsen von Datums- und Zeitangaben nach RFC 2822

# Beschreibung

Dieses Paket bietet Funktionen zum Parsen von Datumsangaben im RFC-2822-Format.

**::clock::rfc2822 parse\_date** *date*
: Dieser Befehl parst eine Datumszeichenkette nach RFC 2822 und gibt das angegebene Datum in Sekunden seit der Epoche zurück. Kann der Befehl das Datum nicht parsen, wird ein Fehler ausgelöst.
