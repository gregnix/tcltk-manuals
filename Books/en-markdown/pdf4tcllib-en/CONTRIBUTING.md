# Contributing to This Book

Workshop book for pdf4tcllib 0.6.7. Corrections are welcome. This is the
English translation of the German book in `pdf4tcllib-de/`.

## What Fits

- Factual errors and examples that do not run (with Tcl and
  pdf4tcl version)
- Pitfalls from your own use, with a small example

## What Does Not Fit

- The drawing API of pdf4tcl itself: see the book *pdf4tcl*
- A general introduction to Tcl

## Style

Workshop book (`booktype workshop`): procedure, commands with output,
pitfalls. No familiar address. Every example is also available as a
script in `beispiele/` and must run with `pruefe-beispiele.tcl -run`.
