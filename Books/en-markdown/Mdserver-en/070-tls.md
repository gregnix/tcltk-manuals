# TLS

## Introduction

HTTPS is optional. Package `tls`, files `--cert` and `--key`, port
`--tlsport` (default 8443). For the LAN behind nginx it is often not
needed: TLS ends at the proxy, mdserver stays HTTP on loopback.

If the package `tls` is missing, the start does not abort. A warning
appears, HTTP keeps running, HTTPS does not.

---

## Building a Certificate

`mkcert.tcl` next to the server. The SAN must be right: whoever calls
`https://192.168.1.50/` needs the **address** in the SAN, not only the
name. `--san` adds further names or addresses and can be given several
times; the CN is always included:

```bash
tclsh mkcert.tcl --cn mdstack --san 192.168.1.50
tclsh mkcert.tcl --cn mdstack --san 192.168.1.50 --san mdstack.lan
```

After creating it, the script reads the SAN back and aborts if it is
missing.

Existing certificates without SAN are replaced — browsers reject them
(`ERR_CERT_COMMON_NAME_INVALID`), even after import.

The OpenSSL option `-addext` (one dash) needs OpenSSL 1.1.1 or later.
If it is missing, `mkcert.tcl` aborts instead of quietly building
without SAN. `--no-san` explicitly forces the old behaviour.

## Files

`mkcert.tcl` writes `server.crt` and `server.key` to `--out`. The
default is the **current directory**, not the script directory. So
change into the target folder first or give `--out`:

```bash
tclsh mkcert.tcl --cn mdstack --san 192.168.1.50 --out /etc/mdserver
tclsh mdserver.tcl --root /srv/md \
    --cert /etc/mdserver/server.crt --key /etc/mdserver/server.key
```

`server.crt` and `server.key` do not belong in Git. Self-signed:
browser warning, development only. Public: Let's Encrypt at the proxy,
not in mdserver.

The key **never** lies below `--root`. mdserver serves every file of
the root whose name does not start with a dot: a `server.key` in
`/srv/md/` can be fetched by anyone with `GET /server.key`.

---

## Summary

- TLS in mdserver is the exception, the proxy is the rule.
- Check the SAN, not only the date; addresses with `--san`.
- `mkcert.tcl` writes to the current directory or to `--out`.
- Key outside `--root`, never in the book or document tree.
