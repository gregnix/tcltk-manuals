# Contributing to This Book

Tool book for tclutils 0.68.0.

## What Does Not Fit

- Speculation without a check
- Patching tclutils source code here (original: workspace `tclutils/`)
- Widget tutorials (book *tkutils*) or stack recipes (book *Utils-Stack*)

## Style

Imperative. As-of line below the H1. Table cells without index markers.
The module reference stays `docs/<modul>.md` in the library tree.
