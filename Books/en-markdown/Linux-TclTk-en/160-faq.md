# FAQ

Short answers with a reference to the chapter that gives the reasons.

---

## Platform and interpreter

**How do I detect Linux in code?**
: `$tcl_platform(os) eq "Linux"`. `platform` is `unix` on macOS too.
  See [tcl_platform and the distribution](020-tcl-platform-und-distribution.md).

**How do I detect Debian or Ubuntu?**
: Read `/etc/os-release`, check `ID` and `ID_LIKE`.
  `/etc/debian_version` exists on Ubuntu too.

**`tclsh9.0` does not find Tcllib, but `tclsh8.6` does. Why?**
: A Tcl 9 under `/opt` does not have `/usr/share/tcltk` in `auto_path`.
  Add pure Tcl packages selectively, not via `TCLLIBPATH` for all
  versions. See [Search paths](050-suchpfade.md).

**`wish` starts Tk 8.6 although `/opt/tcl9/bin` is first in `PATH`.**
: A source build creates `wish9.0`, but no `wish` link. Call it with
  the version number. See [Which Tcl?](030-welches-tcl.md).

**`file normalize ~` returns a path in the current directory under Tcl 9.**
: Tcl 9 no longer expands the tilde. Use `$env(HOME)` or `file home`.
  See [Paths, environment, XDG](040-pfade-umgebung-xdg.md).

**Where do my program's settings go?**
: `$XDG_CONFIG_HOME/<programm>/`, otherwise `~/.config/<programm>/`.

## Encoding

**From cron or systemd, umlauts arrive as `Ã¼`.**
: The locale is missing there, `encoding system` is iso8859-1. Tcl 8.6
  then also reads the script wrongly. Open files with `fconfigure -encoding
  utf-8`, and for 8.6 put the guard at the start of the script. See
  [Encoding and locale](060-kodierung-und-locale.md).

**Tcl 9 aborts when reading an old file.**
: The file is not UTF-8. Tcl 8.6 masked this. Specify the correct
  encoding, or read with `-profile replace`.

## Processes

**How do I open a file or address with the default program?**
: `exec {*}[auto_execok xdg-open] $ziel &`. Under Xfce this goes to
  `exo-open`. See [exec, xdg-open, processes](070-exec-und-prozesse.md).

**`exec` reports an error although the program ran.**
: It wrote to stderr. `errorCode` is then `NONE`.
  `-ignorestderr` or `2>@1`.

**My program hangs when reading the clipboard with `xclip`.**
: It is itself the owner of the selection and blocks in `exec`. Read
  through a channel with `fileevent`, or ask Tk directly:
  `selection get`.

## User interface

**Does Tk run under Wayland?**
: Via XWayland. `tk windowingsystem` remains `x11`. Under Weston,
  window positions there can be neither set nor read; a real
  Wayland session has not been checked. See
  [X11, window managers and Wayland](080-x11-fenstermanager-wayland.md).

**Under Tk 9 my canvas no longer scrolls with the wheel, but with the mouse's side buttons.**
: Tk 9 reports the wheel as `<MouseWheel>`. `<Button-4>` and
  `<Button-5>` are buttons 8 and 9 there. See
  [Mouse, keyboard, clipboard](100-maus-tastatur-zwischenablage.md).

**`<Command-c>` from my Mac code does nothing on Linux.**
: Under Tk 9, `Command` on X11 is `Meta`; in the container and on the
  Xfce workstation no key was assigned to it. Under Tk 8.6 it was Alt. Under `x11`,
  bind `Control`.

**The clipboard is empty after my program has exited.**
: On X11 the program holds the content itself. Without a
  clipboard manager it is gone with the program.

**On the 4K screen everything is tiny.**
: `tk scaling` follows the DPI of the X server. Tk 9 additionally reads the
  scaling of Xfce, MATE, GNOME and `Xft.dpi`. Under 8.6 set
  `tk scaling` by hand. See
  [Fonts, scaling, themes](090-schriften-skalierung-themes.md).

**On one machine my program suddenly has yellow buttons.**
: X resources. Check `xrdb -query` and `~/.Xdefaults`.

**Why doesn't the file dialog look like in GTK programs?**
: On X11 Tk draws it itself. See
  [Native dialogs and desktop integration](110-dialoge-und-desktop.md).

**The panel shows a wrong icon or no icon at all for my program.**
: `StartupWMClass` in the `.desktop` file does not match the class.
  `wish9.0 meineapp.tcl` has the class `Meineapp.tcl`, an image with
  `main.tcl` the class `Main.tcl`. Set it with `-name`.

## Tests

**The CI reports success, but no test ran.**
: `wish` without a display exits with 0. At the start of the test, check
  `package require Tk` and `exit 1`. See [GUI tests with Xvfb](130-gui-tests-xvfb.md).

**Under Xvfb, `event generate` does not arrive.**
: Without a window manager nobody assigns the focus. `update`,
  `focus -force`, `update`. See
  [What the test sets up itself](135-gui-tests-fenstermanager.md).

**`wm iconify` takes two seconds and changes nothing.**
: No window manager. Tk waits in vain for the state change.

## Building and distributing

**Tk's `configure` does not find `XInput2.h`.**
: Install `libxi-dev`. See
  [Building Tk: dependencies](140-tk-bauen-abhaengigkeiten.md).

**My `zipfs mkimg` program does not start on another machine.**
: The base was a dynamic `tclsh9.0` and depends on
  `/opt/tcl9/lib/libtcl9.0.so`. Use a static base (zipkit).
  See [Distributing](150-weitergeben.md).
