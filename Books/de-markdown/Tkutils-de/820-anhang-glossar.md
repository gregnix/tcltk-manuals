# Glossar

---

[Umbrella]{.index}
:   Paket `tkutils`, lädt 53 Kernmodule direkt; braucht Tablelist.

[Namensraum]{.index}
:   `::tkutils::tku<name>` — Befehle immer voll qualifiziert aufrufen.

[Provider]{.index}
:   Speicher-API aus tclutils (`tuprovider`); speist File-Widgets.

[exportselection]{.index}
:   Tk-PRIMARY-Export; Default in tkutablelist 0.4 aus.

[Button-Id]{.index}
:   Rückgabe von `tkudialog::show`; `{id Label}` in `-buttons`.

[Fenster-Override]{.index}
:   `tkuaction::setEnabled id 0 $w` — Enable nur für ein Toplevel.

[placeholder]{.index}
:   tkurender-Typ: Rahmen mit Beschriftung (Standard 200×120) als
    Host-Slot; `slot` leert ihn.

[slot]{.index}
:   `::tkuload::slot` — Platzhalter leeren für Host-Widget.

[tutestrun]{.index}
:   Testrunner aus tclutils; `tclsh tests/all.tcl`.

[Package shadow]{.index}
:   Zweite Kopie eines Pakets auf dem Suchpfad; tkdevtools zeigt sie.

[Pairing]{.index}
:   Empfohlene Versionskombination: tclutils 0.68.0 + tkutils 0.48.0 +
    ctrlutils 0.4.

[tablelist_tile]{.index}
:   ttk-Variante von Tablelist; `tkutablelist` und die `tkutl*`-Helfer
    laden sie. Beide Varianten schließen sich aus.

---
